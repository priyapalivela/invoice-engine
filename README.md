# Intelligent Invoice Extraction Engine

## Overview
An AI-powered invoice extraction system that extracts structured information from invoices using Claude AI and OCR.

## Features
- Upload PDF/Image invoices
- Extract Invoice Number
- Extract Vendor Details
- Extract GST Information
- Extract Invoice Date
- Extract Total Amount
- Download structured output

## Tech Stack
- Python
- Streamlit
- Claude AI
- OCR
- Pillow
- pdf2image
